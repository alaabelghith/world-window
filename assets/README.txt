DROP YOUR 3D SCENE HERE
=======================

File name required: scene.glb

Pick "Beach (GLB)" in the scene list (or open the page with ?scene=glb) to load it.
If the file is missing, that option is hidden and the built-in scene is used.

EXPORT FROM BLENDER
  File > Export > glTF 2.0 (.glb/.gltf), Format: glTF Binary (.glb)

EXPORT FROM HOUDINI
  Labs > Export > glTF ROP, output set to .glb

TIPS
- Centre the scene near the world origin. It is scaled to fit automatically.
- Animations are supported: every clip plays on loop.
- DRACO compression is supported.
- Keep textures embedded in the GLB.
- Deep scenes look best: think of a diorama behind the glass.
